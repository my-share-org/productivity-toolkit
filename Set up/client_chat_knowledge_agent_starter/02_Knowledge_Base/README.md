# Knowledge Base

The knowledge base is intentionally separated by information type.

- `Important_Messages/` — evidence/history index
- `Fixes/` — defects/corrections
- `Requirements/` — requested behavior/capabilities
- `Requirement_Updates/` — changes/clarifications to requirements
- `Enhancements/` — improvements
- `Decisions/` — explicit decisions/approvals/rejections
- `Unknown_Needs_Review/` — important information that cannot safely be classified

Historical records are not deleted when they become superseded.
