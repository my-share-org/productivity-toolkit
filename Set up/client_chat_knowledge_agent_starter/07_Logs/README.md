# Processing Logs

Create one Markdown log per processing run.

Suggested name:
`YYYY-MM-DD_HH-MM_<scope>.md`

The log should record:
- run ID
- date/time
- source files
- number of source messages considered
- important records created/updated
- KB records created/updated
- duplicates/repeats
- superseded records
- missing attachments
- unresolved questions
- user actions required
- files changed
