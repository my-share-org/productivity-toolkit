# Missing Client Attachments (`missing_files.md`)

This document tracks all files, documents, or data packages mentioned or promised in client communications that have **not yet been received**.

## Instructions:
1. As soon as a client mentions a document in chat (e.g. *"I have attached the sheet"* or *"Refer to the design file"*), check if it exists in `03_Attachments/Available/`.
2. If it is missing, add an entry to the table above and mark status as **Pending**.
3. When the client eventually provides the file:
   - Place it into `03_Attachments/Available/` using the standard naming format.
   - Update this table: change status to **Resolved**, record the date received, and link to the file.
