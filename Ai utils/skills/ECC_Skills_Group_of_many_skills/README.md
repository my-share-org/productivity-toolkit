## Update Procedure for AI Agents and Developers

To keep this group of skills synchronized with upstream ECC updates without overwriting local custom modifications, follow this deterministic update procedure:

### Automated Update via AI Agent / CLI
```bash
# Step 1: Clone or fetch latest ECC repository into a temporary directory
git clone --depth 1 https://github.com/affaan-m/ecc.git temp_ecc_sync

# Step 2: Compare upstream skills with current directory to identify additions, updates, or deprecations
python -c "
import os, shutil
src = r'temp_ecc_sync/.agents/skills'
dst = r'Ai utils/skills/ECC_Skills_Group_of_many_skills/skills'
upstream = set(os.listdir(src)) if os.path.exists(src) else set()
local = set(os.listdir(dst))
new_skills = upstream - local
print(f'New upstream skills found: {len(new_skills)}')
for s in new_skills:
    shutil.copytree(os.path.join(src, s), os.path.join(dst, s))
    print(f'Copied: {s}')
"

# Step 3: Remove the temporary clone
rm -rf temp_ecc_sync

# Step 4: Re-run the README generator to update this handbook
python "Ai utils/skills/generate_readme.py"
```

### Manual Update Steps
1. Visit `https://github.com/affaan-m/ecc/tree/main/.agents/skills`.
2. Identify newly added skills or revisions to existing skills.
3. Download or copy the target skill folder into `./skills/<skill-name>/`.
4. Verify that each new skill contains a valid `SKILL.md` with YAML frontmatter.
5. Update this `README.md` index table to reflect newly added skills.

## AI Agent Directive: How to Query This Handbook

When you are instructed: *"Please find the proper skill for my task from this repo, from this folder"*, execute this deterministic 4-step workflow:

1. Analyze User Intent and Stack: Extract the primary engineering task (e.g., refactoring, writing unit tests, building an MVP, fixing a defect, setting up Docker, enforcing WCAG accessibility) and technology stack (e.g., Next.js, Django, Go, Spring Boot, Postgres, Remotion).
2. Scan the Routing Tables:
   - First, check the [Task-to-Skill Fast Routing Matrix](#task-to-skill-fast-routing-matrix) for direct high-frequency matches.
   - Next, navigate to the relevant [Domain Catalog](#functional-domain-catalogs) (1 of 15 technical domains) for detailed options and complementary companion skills.
   - If searching by an exact folder name or keyword, use the [Master Alphabetical A-Z Index](#master-alphabetical-directory-a-z).
3. Inspect the Skill File:
   - Read the corresponding `SKILL.md` located at `./skills/<skill-folder-name>/SKILL.md`.
   - Review the YAML frontmatter `description`, `## When to Use`, `## Core Concepts`, and `## Step-by-Step Instructions`.
4. Apply and Chain Skills:
   - Apply the specific patterns, rules, and edge-case guards documented in the skill.
   - When necessary, chain multiple skills (e.g., for a new Django API endpoint: combine `orch-add-feature` + `fastapi-patterns`/`django-patterns` + `django-tdd` + `django-security`).

## AI Prompting Tips for Hassan and AI Agents

When requesting tasks, you can mention any skill directly to activate its full workflow. Examples:

- *"Please find the proper skill from ECC_Skills_Group_of_many_skills to build a new feature in Django with Celery and TDD."* -> The agent will select `orch-add-feature`, `django-patterns`, `django-celery`, and `django-tdd`.
- *"I need to audit my React components for WCAG 2.2 AA accessibility."* -> The agent will select `accessibility` and `frontend-a11y`.
- *"Help me set up an isolated homelab network with Pi-hole and WireGuard VPN."* -> The agent will select `homelab-network-setup`, `homelab-pihole-dns`, and `homelab-wireguard-vpn`.
- *"I want to optimize LLM token usage and run a multi-agent critique council."* -> The agent will select `token-budget-advisor`, `cost-aware-llm-pipeline`, and `council-multi-model`.
