# Source Chats (`01_Source_Chats/`)

## 1. What This Folder Does
This directory is the permanent, immutable archive for all raw client conversations and chat exports for **{{PROJECT_NAME}}**.

---

## 2. Organization Standard
Organize conversations by communication medium or platform:
- `WhatsApp/` — Raw exports from WhatsApp (.txt, .md) organized in date-range folders.
- `Slack/` — Slack channel exports, thread captures, or transcripts.
- `Email/` — Client email correspondence, briefs, and official approvals.
- `Upwork_Fiverr_Other/` — Communication from freelance or agency platforms.

---

## 3. Strict Rules
1. **Immutable Evidence:** Never edit, censor, or delete raw source chat messages. They are the ultimate source of truth for what was requested and agreed upon.
2. **Text & Markdown Normalization:** When processing raw chat text exports, keeping an adjacent `.md` version formatted with timestamps and sender headers is permitted to make reading easier.
3. **Traceability:** Every incident logged in `02_Incidents/Incidents.md` must link back to the exact source chat file in this folder.
